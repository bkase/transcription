# Dependencies

## Swift Package Manager Dependencies

All dependencies are managed via SPM and declared in XcodeGen's `project.yml`.

### Point-Free Packages
- **swift-composable-architecture** - TCA for state management
- **swift-tagged** - Strongly typed identifiers
- **swift-dependencies** - Dependency injection
- **swift-identified-collections** - Identity-safe collections
- **swift-clocks** - Deterministic time
- **swift-url-routing** - Typed routing
- **swift-snapshot-testing** - Snapshot testing
- **swift-gen** - Property test generators
